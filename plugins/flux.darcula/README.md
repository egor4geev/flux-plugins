# Classic Themes

Classic Dark and Classic Light for Flux: calm color schemes — warm gray and white — on Flux's frosted
glass. The two themes are a pair: choose them as the dark and the light theme of **Settings →
Appearance → Theme → Sync with OS**, and Flux follows macOS between them.

- **Classic Dark** — warm gray neutrals. Code: keywords, commas and semicolons orange, strings green,
  numbers blue, functions yellow, fields and constants purple (constants in italics), annotations
  olive, doc comments green italic.
- **Classic Light** — white islands on pale gray. Code: keywords dark blue, strings green, numbers
  blue, function declarations teal, fields and constants purple, annotations olive, comments gray
  italic.
- In both, plain identifiers and types keep the text color; selection, focus, changed files and diffs
  use the scheme's own colors, and the terminal has a matching ANSI table.

Version 0.2 gave the themes these names: a Flux that had one of them chosen under its former name
keeps it.
