# Darcula & IntelliJ Light

Darcula and IntelliJ Light for Flux: the classic dark and light color schemes of JetBrains IDEs, on
Flux's frosted glass. The two themes are a pair: choose them as the dark and the light theme of
**Settings → Appearance → Theme → Sync with OS**, and Flux follows macOS between them.

- **Darcula** — warm gray neutrals. Code: keywords, commas and semicolons orange, strings green,
  numbers blue, functions yellow, fields and constants purple (constants in italics), annotations
  olive, doc comments green italic.
- **IntelliJ Light** — white islands on pale gray. Code: keywords dark blue, strings green, numbers
  blue, function declarations teal, fields and constants purple, annotations olive, comments gray
  italic.
- In both, plain identifiers and types keep the text color, as IntelliJ IDEA draws them; selection,
  focus, changed files and diffs use the IDE's colors, and the terminal has a matching ANSI table.
