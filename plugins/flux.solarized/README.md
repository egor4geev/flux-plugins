# Solarized

Solarized Light and Solarized Dark for Flux: Ethan Schoonover's palette of sixteen colors with
fixed lightness relationships, on Flux's frosted glass. The two themes are a pair: choose them as
the light and the dark theme of **Settings → Appearance → Theme → Sync with OS**, and Flux follows
macOS between them.

- Code: keywords green, functions blue, types yellow, strings cyan, numbers magenta, comments in
  the quiet base tone.
- The terminal uses the classic Solarized ANSI table.
