# Makefile

Makefiles: highlighting of targets, variables, functions and directives.

## Files

- **Makefile**: `*.mk`, `*.mak`, `Makefile`, `makefile`, `GNUmakefile`.

## Language servers

No language server: none is maintained for Makefiles.

## Highlighting

- [tree-sitter-make](https://github.com/tree-sitter-grammars/tree-sitter-make) `70613f3`, MIT — the grammar and its highlighting query, adapted to Flux's theme scopes (`licenses/`).
- Flux has no language injections yet: the shell commands of recipes are not highlighted.
