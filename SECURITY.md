# Security

A vulnerability in a plugin of the catalog — a plugin doing more than its permissions say, leaking a
token, a package whose checksum doesn't match the index — please report privately, not in a public
issue: **[Report a vulnerability](https://github.com/egor4geev/flux-plugins/security/advisories/new)**
(the Security tab → Report a vulnerability). Only the maintainer sees it until the fix is out.

A vulnerability in Flux itself — its plugin sandbox, the Marketplace's checks — goes to
[Flux's security reports](https://github.com/egor4geev/flux/security/advisories/new); see Flux's
[SECURITY.md](https://github.com/egor4geev/flux/blob/main/SECURITY.md).
